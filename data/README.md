# Auxiliary Data

The lab uses a labelled synthetic population generated deterministically in `src/data/public.ts`. It contains department counts plus dense age and sparse salary distributions sized to the selected table. The shifted-population control transfers 8% of department observations from Support to Sales and 8% of salary observations from the lowest to highest band so learners can see recovery degrade when auxiliary data comes from a different population.

This synthetic dataset is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). It represents no real people and supports no demographic conclusions.
